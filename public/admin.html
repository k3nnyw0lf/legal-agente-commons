Settings: citation checks

The "Check citations" tab looks up each cited case on CourtListener (Free Law Project). It needs a free CourtListener token: sign in at courtlistener.com, open Profile, then Developer Tools, and copy the token. Paste it here. It is saved privately and never shown again.

File fingerprint log

Every file that comes into a case gets a fingerprint (SHA-256), written to a log where each record is chained to the one before it. Changing or removing any record breaks the chain. This check re-works every record.
